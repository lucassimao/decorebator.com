# App Store Screenshot Requirements for Decorebator

## Overview

Screenshots are crucial for App Store conversion rates. They should showcase the app's key features, user interface, and value proposition clearly and attractively.

## Technical Specifications

### iOS App Store Requirements

#### iPhone Screenshots
- **6.7" Display (iPhone 14 Pro Max, 15 Pro Max)**: 1320 x 2868 pixels
- **6.5" Display (iPhone 11 Pro Max, XS Max)**: 1242 x 2688 pixels  
- **5.5" Display (iPhone 8 Plus)**: 1242 x 2208 pixels
- **Format**: PNG or JPEG
- **Color Space**: sRGB or P3
- **Maximum**: 10 screenshots per device type

#### iPad Screenshots
- **12.9" Display (iPad Pro)**: 2048 x 2732 pixels
- **11" Display (iPad Pro, Air)**: 1668 x 2388 pixels
- **Format**: PNG or JPEG
- **Color Space**: sRGB or P3
- **Maximum**: 10 screenshots per device type

### Google Play Store Requirements
- **Phone**: 1080 x 1920 pixels minimum
- **7-inch Tablet**: 1200 x 1920 pixels minimum
- **10-inch Tablet**: 1800 x 2560 pixels minimum
- **Format**: PNG or JPEG
- **Maximum**: 8 screenshots per device type

## Design Guidelines

### Visual Consistency
- **Color Scheme**: Primary orange (#FF7B54), secondary colors from app
- **Typography**: Use app's native fonts (avoid custom fonts in screenshots)
- **Spacing**: Consistent margins and padding throughout
- **Branding**: Subtle app logo/name in corner of each screenshot

### Text Overlays
- **Font**: Bold, readable sans-serif (Helvetica/Arial)
- **Size**: Large enough to read on mobile App Store
- **Color**: High contrast (white text on dark overlay, or dark text on light)
- **Background**: Semi-transparent overlay for text readability
- **Language**: English for primary market, localized for international

### Mobile-First Design
- **Readability**: Text must be readable on small screens
- **Touch Targets**: Show appropriately sized buttons and interactive elements
- **Content Priority**: Most important information in upper half
- **Simplicity**: Avoid cluttered or overwhelming layouts

## A/B Testing Strategy

### Variables to Test
1. **Text Overlay vs No Text**: Clean UI vs promotional messaging
2. **Feature Focus**: Different features highlighted first
3. **Color Schemes**: Different accent colors or backgrounds
4. **Pricing Display**: Emphasize different pricing aspects
5. **Screenshot Order**: Different feature presentation sequence

### Metrics to Track
- **Conversion Rate**: App Store page visits to downloads
- **Engagement**: Time spent viewing screenshots
- **Download Quality**: Retention rate of users from different variants
- **Regional Performance**: How variants perform in different markets

## Production Workflow

### Step 1: Content Creation
- Take high-resolution app screenshots on target devices
- Ensure consistent data (same wordlists, progress indicators)
- Capture multiple states (empty, populated, success states)
- Save originals in highest resolution possible

### Step 2: Design Enhancement
- Add text overlays with consistent styling
- Apply visual enhancements (subtle shadows, highlights)
- Ensure brand consistency across all screenshots
- Create variants for A/B testing

### Step 3: Localization
- Translate text overlays for each target language
- Capture localized UI states where necessary
- Verify cultural appropriateness of content
- Review translations with native speakers

### Step 4: Quality Assurance
- Test display on various device sizes
- Verify text readability at App Store thumbnail size
- Check for consistency in branding and messaging
- Review legal compliance (pricing accuracy, claims)

### Step 5: Upload and Optimization
- Upload to App Store Connect and Google Play Console
- Monitor performance metrics and user feedback
- Iterate based on conversion data
- Update seasonally or with major feature releases

## Success Metrics

### Primary KPIs
- **App Store Conversion Rate**: Target >25% for organic traffic
- **Download Quality**: >70% Day 1 retention from App Store traffic
- **Feature Discovery**: >50% of users try highlighted features
- **Premium Conversion**: Screenshot viewers to paid subscribers

### Secondary Metrics
- **Engagement Time**: Average time viewing screenshots
- **Click-Through Rate**: Screenshots to app details
- **Review Sentiment**: Mentions of features shown in screenshots
- **Support Tickets**: Reduction in "how to" questions for featured functions
